# LIVAPON

## 事業概要

LIVAPON Academy。日本の伝統工芸・クラフトを「作り手から直接学ぶ」越境学習サービス。
Shopify を商取引の正本（顧客・商品・注文・決済・返金）とし、独自DBを利用権限（コース受講）
と予約（体験）の正本とする構成。主な顧客層は訪日外国人・海外在住で日本文化に関心のある層で、
顧客向け画面は英語統一。

差別化ポイントは「コース修了者限定のプレミアム体験」。コースを修了した利用者だけが
予約できる特典体験を用意し、継続的な関係構築につなげている。

## ブランドトーン&マナー

3語のブランドフィロソフィー: **Still（静）** = 急がない・押しつけない・余白がある、
**Precise（正確）** = 一語一語に意味がある・盛らない、**Generous（豊か）** = 出し惜しみ
しないが語りすぎない。

- 色数を絞る、装飾を足さない、写真に語らせて言葉で盛らない（一休.com的な抑制）
- NGワード: `experience/activity`, `buy/purchase`, `amazing/incredible`,
  `limited time/exclusive offer`, `authentic`単体使用 など。早期予約割・期間限定・割引訴求
  といったUIパターンも採用しない
- 星評価・レビュー件数の目立たせ方、割引/セールバッジ、カラフルな装飾アイコンも避ける

## 開発体制・関連リポジトリ

プラットフォーム本体（Next.js + NestJS + Prisma/PostgreSQL、Shopify連携）はエンジニアリング側の
Gitリポジトリ `LIVAPON_platform` で管理。`claude_us` 配下はそのうち、代理店/企画側で扱う
施策の背景資料・設計書の控えを置く場所として運用する（本体の実装・実装計画そのものの正本は
`LIVAPON_platform` リポジトリ側）。
