## [SLIDE 6: 市場分析]

```
| 市場分析

シルバーウィークは、旅行需要が1年で最も集中する期間のひとつです。

三崎方面も例外ではなく、当日の混雑・渋滞・行列が、
本来満足度が高いはずの「まぐろ体験」の質を下げてしまっています。

一方で、まぐろ切符自体の認知は、東京・横浜の日帰り旅行層に
まだ十分に浸透しきっていません。

「知らないから、シルバーウィークにしか行かない」
「シルバーウィークだから、行っても満足できない」
という悪循環が起きています。

ここに、商機があると考えます。
```

## [SLIDE 13: Plan A 概要]

```
[背景色: 白]

                  Plan A

                  Big Catch, Big Buzz.
                  大きな一本を、みんなで見つける。

  シルバーウィーク前から、とにかく「知っている人」の母数を
  最大化することを狙うプランです。

  景品を豪華にすることで応募・拡散のハードルを下げ、
  認知拡大を最優先に設計します。

  ※分散施策（早割・PRクーポン）は実施するが、拡散の勢いを
  削がない範囲の訴求強度にとどめます。
```

## [SLIDE 14: Plan A 具体施策]

```
| Plan A: 具体施策

  SNS懸賞キャンペーン景品案
  「まぐろ一本プレゼント」
   応募条件: まぐろ切符購入＋対象ハッシュタグでSNS投稿
   （※現物の調達・発送は別途費用・オペレーション確認が必要）

  早割訴求
   「購入日から14日前までの予約で10% OFF」
   （シンプルで理解しやすい定番型）

  PRクーポン（インフルエンサー経由購入者向け）
   投稿記載のクーポードコード提示で、三崎オリジナル
   ノベルティをプレゼント

  想定効果: 応募数・SNSインプレッション最大化。
  ただし景品原資が大きくなる分、広告費・分散施策の
  予算余地は他プランより小さくなります。
```

## [SLIDE 16: Plan B 具体施策]

```
| Plan B: 具体施策

  SNS懸賞キャンペーン景品案
  「京急沿線特典セット」
   自社アセット（グッズ・沿線施設利用券等）を活用し、

   カレンダー型の価格変動訴求（今日買うといくら、を可視化）

  PRクーポン（手厚い）
   インフルエンサー経由購入者は、三崎の飲食店で
   使える一品サービス券に加え、次回来訪時の
   再来訪割引クーポンも付与（リピート誘導）

  想定効果: シルバーウィーク以外の購入比率を最も
  高められる設計。認知拡大の勢いはPlan Aより穏やか。
```
