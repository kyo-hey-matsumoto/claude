# website-renewal-2026（drwu.jp ホームページ改編）

## プロジェクト概要

- クライアント: DR.WU
- 使用ドメイン: マーケティング、Webデザイン
- 目的: drwu.jp（Shopify EC）を「商品を並べる場所」から「初めての方をマンデリックへ案内し、購入・継続へつなげる場所」へ転換する
- スコープ: TOPページの構成刷新を起点に、肌悩み別導線・シリーズ別特設ページ・おすすめセット・売れ筋ランキング・LINE連携（30日集中プログラム／会員ロイヤリティ）・コラム強化までを含むサイト全体のIA（ディレクトリマップ）再設計
- 参照資料:
  - 改修意向ドキュメント（ホームページ改編提案、Googleドキュメント）
  - ディレクトリマップ雛形（Googleスプレッドシート、fufutietie.jp向けに作成されたテンプレートを構造流用）

## 成果物

- [directory-map.csv](./directory-map.csv) — 現行ページ階層の棚卸し＋改修意向を反映した改修後ディレクトリマップ
  - 列構成は雛形スプレッドシートに準拠: 第1階層 / 第2階層 / 第2.5階層（コレクショントップ）/ 第3階層 / url / sku展開 / 商品登録 / CMSテンプレート / 掲載情報・実装機能案 / ご提案・相談事項 / 備考
  - 既存ページは「既存」、新設提案は「新設」、整理対象の旧キャンペーン系コレクションは「レガシー・要整理」として区分

## 現状把握のメモ（2026-07-19時点でサイトから確認）

- Shopify構成。sitemapベースでcollectionsが52件確認できるが、うちグローバルナビ掲載は洗顔/化粧水/美容液/フェイスマスク/ベースメイクの5カテゴリのみ
- シリーズ別コレクション（mandelic, hyalucomplex, glutalight, ageversal, squalanex, lab-solutions等）は存在するがナビからの導線が弱い
- 過去キャンペーン系コレクション（happybox2023, 2020年ベストコスメ受賞, 2021-2022-special-set, 20251114-17 など）が未整理のまま残存 → 改修意向ドキュメントの課題③「商品ラインナップの整理不足」に対応する棚卸し対象
- コラムは18本以上蓄積（スキンケア解説／美容ホロスコープ／台湾文化など混在）。カテゴリ整理の余地あり
