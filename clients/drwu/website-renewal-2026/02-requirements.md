# 02. 要件定義

前提: [01-project-overview.md](./01-project-overview.md) の目的・ゴールを満たすための要件を定義する。機能要件は [04-feature-list.csv](./04-feature-list.csv) に、非機能要件・外部連携は [06-external-integrations.md](./06-external-integrations.md) に、それぞれ詳細を分割して記載する。

## 現状の課題（要求の背景）

| # | 課題 | 内容 |
|---|---|---|
| 課題① | マンデリック誘導動線の不足 | 「自分にはどれが合うか」「まず何を使えばいいか」「一番人気は何か」「初回に失敗しにくい商品はどれか」が新規ユーザーに伝わっていない |
| 課題② | 購入・継続導線の弱さ | キャンペーン情報、次回購入商品、相乗効果のある組み合わせ商品、季節おすすめが見えにくい。保湿・UVケアへのクロスセル機会が活きていない |
| 課題③ | 商品ラインナップの整理不足 | 複数シリーズが並存する一方、肌悩み別・目的別の分類が明確でない。過去キャンペーン系コレクションが未整理のまま残存 |

## 機能要件（FR）

改修方針①〜⑨（改編提案ドキュメント）に対応させて定義する。各FRの実装詳細・分類は [04-feature-list.csv](./04-feature-list.csv) を参照。

| FR ID | 要件名 | 内容 | 対応する改修方針 |
|---|---|---|---|
| FR-01 | ファーストビューのマンデリック主役化 | TOP最上部でマンデリックを大きく訴求し、商品ページ・30日集中プログラムへ誘導する | ① |
| FR-02 | 開催中キャンペーンの一覧表示 | 初回限定／LINE登録特典／セット購入特典／季節企画をTOP・専用ページに表示する | ② |
| FR-03 | 肌悩みから選ぶ導線 | 毛穴・ざらつき／乾燥・うるおい／くすみ・透明感／ハリ・年齢肌／敏感肌／UV対策の6区分から商品へ誘導する | ③ |
| FR-04 | おすすめセット（バンドル販売） | 目的別セット（例: つるん肌30日集中セット、乾燥対策セット、UV対策セット）を商品として販売する | ④ |
| FR-05 | 売れ筋ランキング表示 | 人気商品TOP5〜10を、悩み別の補足コピー付きで表示する | ⑤ |
| FR-06 | シリーズ別導線・特設ページ | マンデリック／UV等の重点商品について、シリーズ特徴・比較表・使用方法・組み合わせ提案を含む特設LPを構築する。その他シリーズは既存コレクションを活用する | ⑥ |
| FR-07 | 使い方ガイド | マンデリックなど角質ケア商品の購入前後の不安解消のためのガイドコンテンツを設置する | ⑦ |
| FR-08 | LINE公式連携・30日集中プログラム | LINE経由で使用方法・頻度・保湿方法・不安解消をサポートする導線を設置する。マンデリック購入者への自動配信を含む | ⑦ |
| FR-09 | LINE連携会員登録・ロイヤリティプログラム | LINE連携時／新規会員登録時のポイントプレゼント、誕生日ポイント・クーポンを実装する | ⑧ |
| FR-10 | コンテンツ（コラム）強化 | コラムのカテゴリ整理・絞り込みUIを追加し、購入以外の訪問目的を創出する | ⑨ |
| FR-11 | 既存コレクションの棚卸し・整理 | 過去キャンペーン系コレクション（happybox2023等）・重複コレクション（UV/シリーズ系）を統合し、301リダイレクトまたは非表示化する | 課題③ |

## 非機能要件（概要）

詳細・一覧は [06-external-integrations.md](./06-external-integrations.md) を参照。ここでは要件定義の一部として観点のみ列挙する。

- パフォーマンス: TOPページはセクション数が増えるため表示速度（LCP等）を既存同等以上に維持する
- 計測: セクション単位でのクリック・コンバージョン計測（GA4等）ができること
- SEO: コレクション統廃合に伴うURL変更は301リダイレクトで評価を継承する
- セキュリティ・個人情報: LINE連携・会員登録で扱う個人情報（氏名・誕生日・購入履歴）の取り扱いに関するポリシー整合
- 保守性: テーマカスタマイズ／アプリ導入後も、コラムやキャンペーンバナー等は非エンジニアが更新できること

## 対象外（スコープ外）

- 多言語対応・海外向け展開
- 実店舗・卸／BtoB向け機能
- Shopify以外のカートへの移行

## 前提条件・制約

- Shopifyプラットフォームを継続利用する
- 開発体制（内製／外部ベンダー）は未確定 → [07-wbs.csv](./07-wbs.csv) は人日ベースの汎用見積もりとする
- リリース時期は開始時期に依存せず、全工程4ヶ月を目安とし、機能追加・変更に応じて超過分だけ後ろ倒しする
- LINE連携アプリは CRM PLUS on LINE／StoreCRM のいずれかを想定するが未確定（[06-external-integrations.md](./06-external-integrations.md) で比較）
