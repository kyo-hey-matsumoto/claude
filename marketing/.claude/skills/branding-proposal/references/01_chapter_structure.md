## 表紙の作り方

### 必須要素（上から順）
1. クライアント企業名 + 部署名 + 「御中」
2. 案件名（和文・少し大きめ・明朝体）
3. 英文サブタイトル + "Branding Proposal X.X" のバージョニング
4. 短い区切り線 `—`
5. `Date : YYYY.M.D` + `confidential`
6. 社名/ロゴ（自社の正式表記を使用）

### エビデンス
- PLUS推し活: 「プラス株式会社 ステーショナリーカンパニー 御中 / 推し活 向け企画 / Branding Proposal 1.0 / Brand for "Oshikatsu" Branding Proposal 1.0 / Date : 2023.12.18  confidential」
- Gora: 「株式会社オープンハウスグループ 事業開発部 / 株式会社オープンハウスホテルマネジメント 御中 / Hakone Gora Hotel / Branding Design Proposals / Date : 2025.3.25  confidential」

### レイアウト指示
- 左寄せ。中央寄せはしない。
- 背景: ライトグレー (#D0D2D2 〜 #DDDDDD) or オフホワイト。**真っ白は避ける**。
- 英文タイトル: 明朝体（Adobe Garamond Pro / 游明朝）。和文タイトル: 同じく明朝体で1.5倍程度大きく。
- 装飾は最小限。ロゴと社名以外は触らない。

## Introduction の作り方

### 構文テンプレ
```
単に[クライアントが言いそうな表面的目標]を作ることが目的ではありません。

[本来の目的1行目]、

[本来の目的2行目]ためのご提案です。
```

### エビデンス
- PLUS推し活/黒文具で同一文面を流用:
  > 単にカッコいい・かわいいパッケージを作ることが目的ではありません。
  > 新しく立ち上げるこのブランドのことを、多くの人に知っていただき、
  > 理解し、買っていただくためのご提案です。

### レイアウト
- 中央寄せ。本文は28-32pt級。改行で間を作る。
- 余白を多めに取る（上下に各40%程度）。
- 背景は白 or オフホワイト。

## 与件整理の作り方

### 構造
1. 最上部に **＜製品コンセプト＞** ラベル付きの囲みボックス
2. その下に3要素を縦並び:
   - **製品:** 〜
   - **ターゲット:** 〜
   - **売り場:** 〜
3. 場合により「他社 vs 自社」の左右対比表を追加

### エビデンス（PLUS推し活 P3）
```
＜製品コンセプト＞
推し活とともに進化する文房具・収納用品
第一弾/ファイル収納用品

他社                              PLUS
「推し活」=（一過性の）ブーム      「推し活」= 生き方そのもの
機能: 「見せる」が主流             機能: 「見せる」< 「しまう」
デザイン: シンプルでガーリー       デザイン: どんなスタイルにも合うシンプルな...
ユーザー: 学生など若めの層         ユーザー: 社会人の女性・オタク以外も使える
```

### エビデンス（黒文具 P3）
```
＜製品コンセプト＞
男性をメインターゲットとした
「かっこいい」「細部へのこだわり」「ハイスペック」
を魅せるカラーデザイン横断企画

製品:    ハイエンドではなく、日常づかいの文房具(価格)
         シンプルでスタイリッシュなデザイン
         デザインだけでなく、機能の良さも伝わるようなブランドにしたい

ターゲット: 20〜30代の男性
            働き出して金銭的に余裕ができてきたので、持ち物にもこだわりたい
            機能とデザインを吟味して、自分で選んで購入したい

売り場:  ロフトやハンズなどの量販店: 売り場で手に取って気に入ったら購入
         書店: 機能だけでなく、デザインも重視される?
         オンライン: 広告→WEBサイトを見て購入、SNSで口コミを見て購入
```

## 競合分析の2パターン

### パターンA: 4象限ポジショニングマップ
**使い時**: 価格帯と方向性で明確に住み分けが見えるカテゴリ（文房具、コスメ、家電など）。

**構造**:
- 縦軸: 価格高 ↔ 価格低
- 横軸: 例「贅沢・こだわり ↔ 定番・実用性」
- 各象限に競合ブランドの実物写真+価格レンジを配置
- **「空白地帯」に結論ボックス**（オレンジ背景、白文字）を置く

**エビデンス**: 黒文具 P4
> オレンジボックス: 「文房具にこだわりを持つ男性にとって、低価格帯のものは選択肢が少ない」

### パターンB: 並列カード型
**使い時**: 競合の世界観が独自で、軸での比較が難しいカテゴリ（ホテル、メディア、ストア）。

**構造**:
- 3-4社を写真+ロゴ+一文コピーで並列
- 各社の世界観コピーを引用（"" で囲んで斜体）
- 「こういうところに取り上げられたい」と理想形メディア記事のスクショも追加可

**エビデンス**: PLUS推し活 P4-5（Pic Too / サンリオコラボ / オリジナルメディア / mitte）
**エビデンス**: Gora P4 「bar hotel 箱根香山」「夜の帳が降りる頃」を「独自性があり、気になる言葉と、1枚のビジュアル」とコメント付きで紹介

## Who / ターゲットの作り方

### 構造
- 短い箇条書き 3-5項目（中央寄せ、リスト記号は「・」）
- ペルソナの写真 or Instagram投稿のスクショ（URL併記）
- ペルソナが見ているメディアの実例リンク

### エビデンス（PLUS推し活 P5）
```
・推し活をしている社会人（女性メイン?）
・普段の仕事場などでは、オタクであることを主張しない
・自分のこだわりや、審美眼を持っている
 →流行だけに左右されない / 自分らしさも重視

[Instagram URL1]  [Instagram URL2]
```

### エビデンス（Gora）
- 3つの箇条書きの後に黄色マーカーで「14室を埋めるためのニッチなターゲティング」と結論
- 結論直下に「ゆえに、広く浅く届けるメッセージよりも、より深く尖らせたメッセージの方が良さそう」と方針

## 市場分析の作り方

### 構造
- 短文4-5行で現状の課題を述べる
- 最終行に **「ここに、商機があると考えます。」** で締める

### エビデンス（PLUS推し活 P6）
> 収納用品の機能競争に、イノベーティブなことはあまりない。
> 些細な、痒いところに手が届くようなこと。
> 今市場にある競合ブランドは、機能がユニークなものもあるが、
> ブランドの世界観が他社追随なため、全部同じに見えてしまう。
> ここに、商機があると考えます。

## RTB (Reason to Believe) の作り方

### 構造
- 章タイトル直下に補足: 「消費者がそのブランドや商品を信頼するに足る理由や根拠、訴求」
- 2項目（例: 機能性 / デザイン性）をベン図 or 円対比で表現
- 各円の中に箇条書き（3項目程度）
- 円の下に結論一文「○○と○○を融合させるようなコンセプトが必要。」

### エビデンス（黒文具 P11）
```
機能性                          デザイン性
普段使いとして使いやすい機能。     黒をベースとして、
しかし、他社製品と比べて突出して    機構を見せるデザイン(修正テープ)。
機能性が高いというわけでもない。    メカニカルでスタイリッシュな印象。

下に結論: 機能性と、デザイン性を融合させるようなコンセプトが必要。
```

## ユーザー接点整理の作り方

### 構造（マトリクス）
- 横軸: **認知 → 興味 → 検討 → 購入 → 共有** の矢印フローチャート
- 縦軸: **売り場** / **オンライン** の2行
- 各セルにユーザーの心の声をピンク色のチャットバブルで配置
- 接点アセット名（パッケージ、什器、POP、SNS広告、ブランドサイトなど）を**黄色マーカー**で帯状にハイライト

### エビデンス（PLUS推し活 P9-10）
- 売り場×認知: 「この商品、なんだろう？」「パッケージがかわいいな」
- 売り場×興味: 「ああ、たしかにこうゆうの今までなかった！」「痒いところに手が届く！」
- 売り場×検討: 「この世界観、面白い！」「めっちゃ共感できる！」
- 売り場×共有: 「SNSにあげよう」
- オンライン×共有: 「推し活仲間に教えてあげよう」

### 後続ページ: 接点での問い
> 売り場で目立つフックがあるか？
> （些細な）機能がしっかり伝わるか？
> 共感できて差別化できる世界観があるか？
> 話題を生み出すことができるか？

これらの「問い」は後段のコンセプト案が応えるべき要求事項として機能する。
