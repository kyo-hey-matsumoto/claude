# 04. ネーミング案の作り方

ネーミングは「コンセプトを実直に体現する」のが松本流の鉄則。3案前後で出す。

## ネーミング3タイプの混ぜ方

各コンセプト案につき、以下の3タイプを混在させて出すと、議論しやすくなる。

### Type 1: 造語タイプ
コンセプトを構成するキーワードを合成 or 再構築した新語。

#### エビデンス
- **KURODUCT** = 黒 + product（黒文具 type.A）
- **OSHIKARA EIYOU LAB.** = 推しから栄養＋ラボ表記（PLUS Idea.B）
- **NUT(＋)** = 栄養素 NUT + PLUSの社名要素（PLUS Idea.B）

#### 作り方
1. コンセプトの2-3単語を分解
2. それぞれを英訳/カナ訳/略語化
3. 合成 or 字面の良さで取捨

### Type 2: 直訳/英語フレーズ系
コンセプトをそのまま英語フレーズで表現。覚えやすく、海外展開も視野に。

#### エビデンス
- **Vitamin Storage**（PLUS Idea.B）
- **Urban Cruise, Urban Stay.**（Roppongi A）
- **New Casual in New Life**（Roppongi B）
- **A Little Good**（PLUS Idea.C）
- **Be Free, Be Smart.**（Roppongi）

#### 作り方
1. コンセプトを5-8単語の英語フレーズに翻訳
2. 韻 or リズムで整える
3. 「カンマで区切る／ピリオドで締める」と松本流の余韻が出る

### Type 3: シリーズ展開骨格
今後のラインアップ展開を示唆する構造を持つネーミング。

#### エビデンス
- **type:KIRU / type:KAKU / type:KESU**...（黒文具 type.A、機能名でシリーズ展開）
- **KURODUCT#01, #02, #03**...（同案件、ナンバリングで継続性を示す）
- **Freaks Model by PLUS**（PLUS Idea.C、by PLUSという冠で多モデル展開を示唆）

#### 作り方
1. 親ブランド名を決める
2. サブシリーズの差分を一語で表せる規則を定める（機能名、数字、年号、シーズン、用途など）
3. 親:子の階層がシンプルに見えるネーミングに整える

### Type 4: 日本語直球タイプ（任意の追加）
カタカナや漢字で素直に表現するパターン。

#### エビデンス
- **オタク思考の文房具**（PLUS Idea.A）
- **わがままなオタクがつくった文房具**（PLUS Idea.A）

#### 作り方
直訳的に、「○○な△△」のフォーマットで作る。ターゲットの自虐や本音を含めると親近感が出る。

## ネーミング・ポイント（リード文）の書き方

ネーミング案を提示するページの上部には「ネーミングのポイント」というラベルと、1-2行のリード文を必ず置く。

### テンプレ
```
ネーミングのポイント

[コンセプトとの整合性を一文で]、
[トーン or 制約条件を一文で]。
```

### エビデンス
- PLUS Idea.A: 「『オタク』へのイメージを逆手に取り、誰もが手に取ってみたくなるような表現を検討します。」
- PLUS Idea.B: 「コンセプトを実直に体現するために、架空の栄養補助食品ブランドと、収納（文房具）用品であることが両立するようなネーミングを目指します。」
- PLUS Idea.C: 「機能性がしっかり伝わるようなネーミングデザインに。シュッとしていてスタンダードな感じ？」

## ネーミングの由来説明

ネーミングを並べるだけでなく、**各案ごとに「なぜそのワードか」の解説**を添える。これが説得力の差を生む。

### エビデンス（Roppongi A "Urban Cruise, Urban Stay." の解説）
> "urban"というワードでリッチ感、先端感も担保
> 都会を感じ、巡り、満喫してほしいという意味を込める
> 「ホームステイ」を想起させる "Stay"を起用することで
> 期間を問わない「滞在」を表現
> 「動」と「静」の共存

→ 各単語（urban / cruise / stay）に対して別々の役割を割り当てて解説している。

### 解説テンプレ
```
[単語1]というワードで [機能や情緒1] を担保
[単語2]という表現で [機能や情緒2] を表現
[単語1] と [単語2] の組み合わせで [統合された世界観]
```

## やってはいけないネーミング癖
- **1案だけで決め打ち** — 必ず複数案
- **由来説明なし** — 必ず1案ごとに解説
- **コンセプトと無関係なオシャレ感だけのネーミング** — 「ターゲットが何を読み取るか」を必ず考える
- **長すぎる名前**（4語以上の英文フレーズはタグライン扱いにし、ブランド名は短く）
- **競合と読み違いが起きる近い綴り** — 簡単な検索で類似名がないことを確認する旨を「※商標調査は別途」と注釈で書く

## ネーミング・チェックリスト

提案するネーミング1案ごとに以下を確認:

- [ ] コンセプトとの関係が一文で説明できる
- [ ] 読み・発音が明確（"何て読むの？"と聞かれない）
- [ ] 商標調査が別途必要であることを注釈に書いた
- [ ] 他案と方向性が分散している（全部造語、全部直訳になっていない）
- [ ] シリーズ展開可能性を意識した
- [ ] 英語表記と日本語表記の両方を提示している
