# 06. レイアウト・タイポグラフィ・色使い

松本流のミニマルなブランドエージェンシー流フォーマット。

## ページサイズ・アスペクト比

- **横長** が原則
- A4横（297×210mm）、または 16:9（プレゼン用）、または 1.4:1 程度
- 縦置きA4は使わない

## 1ページ1メッセージの原則

1スライド内に複数のテーマを混ぜない。情報が多くなりそうな場合は分割する。

### エビデンス
- PLUS推し活 P9-10: 「ユーザーとの接点整理」を2ページに分けている
- Gora: 「プロジェクトの目的」を2ページに分けている

## ヘッダー / フッターのレイアウト固定

### ヘッダー（全ページ共通）
左から:
- 案件名 + バージョン（薄いグレー 50% / 7-8pt）
- `confidential`（同色）
- 右端: （必要であれば自社URLを同色で配置。無くても可）

### エビデンス
```
[左] 推し活向け企画 Branding Proposal 1.0 [中央] confidential [右] （任意でURL）
```

### フッター（全ページ共通）
- 左下: 自社ロゴまたは社名（任意）
- 中央〜右下: 住所/電話/FAX（旧版）or 案件名+日付（新版）

### エビデンス（旧版・PLUS推し活）
```
barbizon80 3F 1.14.21 jingumae shibuya-ku tokyo 150-0001, japan  telephone 03.6455.5097  facsimile 03.6455.5098
```

### エビデンス（新版・Roppongi）
```
Toikyo | 2018  ...  （社名）
```

→ 案件によりフッターは簡略化されている。**ヘッダーは絶対固定、フッターはスタイル裁量**。

## 章タイトルの書式

ページ左上に**細い縦線 + 章タイトル**の組み合わせ。

### 書式
```
| Introduction
| 与件整理
| 参考: 競合ブランド
| Who（target）
| 市場分析
| RTB (reason to believe)
   [補足] 消費者がそのブランドや商品を信頼するに足る理由や根拠、訴求
| ユーザーとの接点整理
| Idea.A
| type.A
```

- 縦線「|」は本文文字の高さと同じくらい
- 章タイトル下に細いアンダーラインを引くケースもある
- 補足説明は章タイトル直下に **xx-small サイズ** で添える（RTB の例）

## タイポグラフィ

### フォント選択
- **タイトル・キャッチコピー**: 明朝体
  - 英文: Adobe Garamond Pro, Trajan Pro, IM Fell English系
  - 和文: 游明朝、A1明朝、リュウミン系
- **本文・データ・表**: ゴシック体
  - 英文: Helvetica Neue, Inter, IBM Plex Sans
  - 和文: 游ゴシック、Noto Sans CJK、平成角ゴシック系

### サイズ目安（16:9 スライド前提）
- 表紙の和文タイトル: 60-72pt
- 表紙の英文サブタイトル: 28-32pt
- 章タイトル: 18-22pt
- 中表紙のキャッチ: 48-72pt（明朝体・中央寄せ）
- 本文/箇条書き: 14-18pt
- 注釈・ヘッダー: 8-10pt

### 行間 / 字間
- 明朝体タイトルは**字間広め**（10-20%）
- 本文は標準字間で、行間1.4-1.6倍
- 改行で**間を作る**（特に Introduction や中表紙）

## 余白の使い方

- セクション仕切り（中表紙）は**上下40%の余白**を取る
- 本文ページでも上下に20%程度の余白
- 「真ん中だけにテキスト」のレイアウトを恐れない

## 色使い

### 基本パレット
- 背景: 白 or オフホワイト（#FAFAFA）or ライトグレー（#D0D2D2）
- 本文: ほぼ黒（#1A1A1A 〜 #333333）
- ヘッダー/フッター: グレー50%（#888888）

### アクセントカラー（用途別）
- **黄色マーカー** （#FFFF99 / #FFE96B）: 重要な一文だけハイライト
  - エビデンス: Gora「集客のためのコミュニケーション」「14室を埋めるためのニッチなターゲティング」
- **オレンジ/赤の結論ボックス**: 白文字 + #FF5A2A 〜 #FF4040 背景
  - エビデンス: 黒文具 P4 「文房具にこだわりを持つ男性にとって、低価格帯のものは選択肢が少ない」
- **ピンクのチャットバブル**: #F8C4C4 〜 #F5A8A8 で、ユーザーの心の声を吹き出しに
  - エビデンス: PLUS推し活、黒文具のユーザー接点整理ページ

### 中表紙の背景色（章ごとに変える）
- ピンクベージュ（#E8C8B8）: 黒文具「コンセプト案」中表紙
- 紺グラデ（#1F2A44 → #2F3A55）: Roppongi「Concept (世界観)」中表紙
- グレー（#A6A8A8）: Gora「旅前(旅後)のコミュニケーションについて」中表紙
- 白: Roppongi の各コンセプトページ

→ **章が切り替わるたびに背景色を変える**ことで、リズムと節目を作る。

## 中表紙のレイアウト

```
[背景色を変えた1ページ]

[ヘッダーのみ固定]

           [大きな明朝体・中央配置・短文]

[ロゴだけのフッター]
```

### エビデンス（黒文具「コンセプト案」中表紙）
- 背景: ピンクベージュ
- テキスト: 「コンセプト案」 明朝体、中央寄せ、48pt程度

### エビデンス（Roppongi「Concept (世界観)」中表紙）
- 背景: 紺グラデ
- 白枠ボックス内に「Conept (世界観)」明朝体白文字

### エビデンス（黒文具「Facts and Acts」中表紙）
- 背景: 白
- 「Facts and Acts」（英・大）/ 「事実と行動。」（和・小）の2層

## 比較・対比のレイアウト

### 左右対比表
2列のテキストブロックを左右に配置。間に縦線を入れることもある。

### エビデンス（PLUS推し活 P3 「他社 vs PLUS」）
```
他社                              PLUS
・「推し活」=(一過性の)ブーム       ・「推し活」= 生き方そのもの
・機能: ...                       ・機能: ...
```

### ベン図（円対比）
2つの円を重ねて、それぞれに項目、重なった部分 or 下に統合一文。

### エビデンス（黒文具 P11 RTB）
- 左円: 機能性
- 右円: デザイン性
- 下: 「機能性と、デザイン性を融合させるようなコンセプトが必要。」

### 4象限ポジショニングマップ
- 縦軸・横軸を直交させる
- 各象限に競合ブランドの写真を配置
- 空白象限に結論をオレンジボックスで

## フロー図（ユーザー接点）

### 構造
- 5つの「矢印型」ブロック: 認知 → 興味 → 検討 → 購入 → 共有
- 縦に2行（売り場 / オンライン）の帯
- 各セルにピンク色のチャットバブル

### 接点アセット名は黄色マーカー帯で表現
- 「パッケージと、什器、POP」← 黄色マーカー帯
- 「SNS、オンラインアド」← 黄色マーカー帯
- 「ブランドサイト」← 黄色マーカー帯

## ビジュアル参考（mood board）のレイアウト

### グリッドの組み方
- 4-9枚の写真を均等グリッドで並べる
- 写真サイズは揃える（少し変化させてもOK）
- 各写真の下 or 横に1-2行の短いキャプション

### サブタイトルの位置
- 上部に **「○○をテーマに、△△をモチーフにする」** のサブタイトル
- フォントは本文サイズ、明朝体

### エビデンス（Gora デザインコンセプトA方向）
- サブタイトル: 「強羅をテーマに、円をモチーフにする」
- 9枚の写真グリッド（書道、宇宙、円のアートワーク、自然景観、参考ロゴ「offday」）

## ネーミング案のレイアウト

### 構造
```
ネーミングのポイント

[リード文 1-2行]

[ネーミング案1]
[ネーミング案2]
[ネーミング案3]
```

- ネーミング案は中央寄せ、各案の間に大きな余白
- 案ごとにフォントを変えてもよい（明朝/サンセリフのミックス）

### エビデンス（PLUS Idea.B ネーミング）
```
ネーミングのポイント

コンセプトを実直に体現するために、架空の栄養補助食品ブランドと、
収納(文房具)用品であることが両立するようなネーミングを目指します。

           OSHIKARA EIYOU LAB.
                  NUT(＋)
           Vitamin Storage
```

## クロージングページ

最後のページに **"FILE END"** を白背景・中央配置で置く（任意）。

### エビデンス
- 黒文具最終ページ: "FILE END"（中央サンセリフ太字）

## NGレイアウト
- ヘッダー/フッターをページごとに変える
- 1ページに3つ以上のテーマを詰め込む
- 文字を小さくして情報を詰める
- 写真をトリミングせず元のアスペクト比のまま並べる（グリッドが揃わない）
- 中表紙を省く
- 全ページ白背景（リズムが失われる）
