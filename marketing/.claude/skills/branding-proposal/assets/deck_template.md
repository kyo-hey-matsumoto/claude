# deck_template.md

ブランディング企画書のスライド雛形（Markdown版）。各スライドを `---` で区切る。pptx skill に渡すときは1区切り = 1スライド。

下記の `{プレースホルダー}` を案件情報で埋めて使う。

---

## [SLIDE 1: 表紙]

```
{クライアント企業名} {部署名} 御中

{案件名_和文}
Branding Proposal {バージョン}
Brand for "{案件名_英文サブタイトル}" Branding Proposal {バージョン}

—

Date : {YYYY.M.D}    confidential
```

## [SLIDE 14-N: 各アイデア構造（5パート x 案数）]

```
| Idea.{A/B/C}

  {コンセプト名 英文}（任意）

  {説明文 3-5行}
  {動詞は "目指します" "狙います" "展開し" で締める}

### Part 3: ビジュアル参考

```
| Idea.{A/B/C}

  {サブタイトル: ○○をテーマに、△△をモチーフにする}

  [写真グリッド 4-9枚]

  [各写真のキャプション: 1-2行]
```

### Part 4: 表現アイデア（任意）

```
| Idea.{A/B/C}

  ・{表現案1の説明}
  ・{表現案2の説明}

```

```

                  {ネーミング案3: シリーズ展開骨格}

## 章数の目安

- ミニマム版（10-15ページ）: 表紙、Introduction、与件整理、競合、ターゲット、市場分析、RTB、コンセプト中表紙、案A（コンセプト+ネーミング）、案B（コンセプト+ネーミング）、案C（コンセプト+ネーミング）、FILE END
- 標準版（20-30ページ）: 上記 + 各案のビジュアル参考+表現アイデア+ユーザー接点整理
- フル版（40-50ページ）: 上記 + 各案を5-7ページに展開 + 詳細な競合分析 + KEYWORD/世界観コピーページ
