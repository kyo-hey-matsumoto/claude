# 完成度チェックリスト

企画書のドラフトができたら、出力前に以下のチェックを必ず実行する。

## 1. 構造チェック

- [ ] 表紙にクライアント企業名・部署名・「御中」がある
- [ ] 表紙に案件名（和文）と英文サブタイトルの両方がある
- [ ] 表紙に "Branding Proposal X.X" のバージョン表記がある
- [ ] 表紙に日付と "confidential" がある
- [ ] Introduction が「単に〜することが目的ではありません」で始まっている
- [ ] 与件整理に「製品コンセプト」を囲みで提示している
- [ ] 与件整理に製品/ターゲット/売り場の3要素がある
- [ ] 競合分析がポジショニングマップ or 並列カード型のどちらかで構成されている
- [ ] 競合の各社について世界観コピーを引用している
- [ ] ターゲット/Whoページがある
- [ ] 市場分析の最後に「ここに、商機があると考えます。」または同等の断定がある
- [ ] RTBで二項対立（例: 機能性 × デザイン性）を可視化している
- [ ] RTBの下に統合する結論一文がある
- [ ] ユーザーとの接点整理マトリクスがある（認知→興味→検討→購入→共有）
- [ ] コンセプト案の中表紙がある（色を変えた背景）
- [ ] **コンセプト案が3案以上ある**（2案でも可、ただし理由を明示）
- [ ] 各コンセプト案が5パート構造（中表紙→コンセプト名→ビジュアル参考→[表現アイデア]→ネーミング）
- [ ] 各案のコンセプト名が英+和ペアになっている
- [ ] 各案のネーミング案が3つ以上ある
- [ ] 各ネーミング案に由来説明がある

## 2. コピー・トーンチェック

- [ ] 主要キャッチコピーが英+和ペアになっている
- [ ] セクションタイトルに疑問形が1-2箇所ある
- [ ] Introduction が「否定→本質」の構文
- [ ] 自虐・親しみ系の注釈が1-2箇所ある
- [ ] 文末動詞が「目指します」「狙います」「設計します」「展開します」を含む
- [ ] 「※費用境界」の注釈がある（撮影・イラスト・ネーミング確定・商標調査など）

## 3. レイアウト・ビジュアルチェック

- [ ] 横長レイアウト（A4横 or 16:9）になっている
- [ ] 1ページ1メッセージの原則を守っている
- [ ] ヘッダーが全ページ固定（案件名・confidential・URL）
- [ ] フッターが全ページ固定
- [ ] 章タイトルに「| 」プレフィックスがある
- [ ] タイトル・キャッチは明朝体、本文はゴシック体
- [ ] 中表紙の背景色が章ごとに変わっている
- [ ] 黄色マーカーが重要箇所のみに使われている（多用しない）
- [ ] オレンジ/赤の結論ボックスが結論にだけ使われている
- [ ] ユーザー接点整理のチャットバブルがピンク系
- [ ] 余白を十分に取っている（特に中表紙とIntroduction）

## 4. ロジックチェック

- [ ] 「クライアントの言いそうな表面的目標」と「本来の目的」が対比されている
- [ ] 競合分析と RTB が論理的につながっている
- [ ] RTB と 各コンセプト案の方向性が論理的につながっている
- [ ] 接点整理で挙げた「問い」に、各コンセプト案がそれぞれ別の角度で応えている
- [ ] 各コンセプト案の方向性が分散している（全部同じ抽象度・トーンになっていない）
- [ ] 各ネーミング案のタイプが分散している（造語 / 直訳 / シリーズ展開）

## 5. クライアント別最終確認

- [ ] クライアント名の漢字・カタカナ表記に誤りがない
- [ ] 部署名が正確
- [ ] 製品名・サービス名の正式名称が正確
- [ ] 引用したURLやSNSアカウントが現存する
- [ ] 競合ブランド名・写真の使用許諾の検討
- [ ] 「※商標調査は別途」と書いてある

## 6. 出力チェック

- [ ] ファイル名規則: `{YYMMDD}_{案件略称}_{バージョン}.pptx` または `.pdf`
- [ ] ページ番号は不要（松本流ではページ番号を打たない）
- [ ] 出力後にスライドショーで通しで眺めて、リズムを確認する
- [ ] 最終ページが "FILE END" or 同等のクロージング（任意）

## 7. 出力ファイル形式の最終確認

ユーザーが要求する形式に応じて出力する:

- `.pptx` → pptx skill で生成
- `.pdf` → pdf skill で生成、または pptx → PDF変換
- `.md` → このまま提示

それぞれの skill ガイドラインに沿うこと。
