# kickoff_questions.md

新規案件のキックオフ時にクライアント / 自分自身に問うヒアリング質問集。AskUserQuestion ツールで2-3問ずつ聞く。

## A. 表紙情報（必須）

1. **クライアント企業名・部署名・「御中」表記の正式形は？**
   - 例: 「プラス株式会社 ステーショナリーカンパニー 御中」
   - 例: 「株式会社オープンハウスグループ 事業開発部 / 株式会社オープンハウスホテルマネジメント 御中」

2. **案件名（和文）は？**
   - 例: 「推し活向け企画」「黒文具企画」「Hakone Gora Hotel」

3. **英文サブタイトルは？**
   - 例: Brand for "Oshikatsu" Branding Proposal 1.0
   - 例: Brand for "Black Stationary" Branding Proposal 1.0
   - 例: Branding Design Proposals

4. **バージョン番号は？**（1.0 から始める）

5. **提出日付は？**（YYYY.M.D 形式）

## B. 与件・現状（必須）

6. **対象プロダクト・サービスのカテゴリーは？**
   - 文房具/収納/家電/コスメ/食品/アパレル/ホテル/施設/メディア/サービス...

7. **クライアントから提示されている製品コンセプト（一文）は？**
   - 例: 「推し活とともに進化する文房具・収納用品」
   - 例: 「男性をメインターゲットとした『かっこいい』『細部へのこだわり』『ハイスペック』を魅せるカラーデザイン横断企画」

8. **何を提案するのか（提案範囲）?**
   - コンセプト策定のみ
   - コンセプト + ネーミング
   - コンセプト + ネーミング + VI
   - パッケージデザイン提案
   - 空間ブランディング
   - 一気通貫（コンセプト + VI + 空間 + サービス）

9. **競合と思われるブランドを3-5社挙げると？**

10. **クライアントが「これは絶対やりたい/やりたくない」と言っていることはあるか？**

## C. ターゲット（必須）

11. **メインターゲットの像は？**
    - 年代
    - 性別
    - 職業/ライフスタイル
    - 価値観
    - 購買動機

12. **ターゲットがよく見ているメディア / SNS / 雑誌 / インスタアカウントは？**

## D. 売り場・チャネル（プロダクト系の場合）

13. **想定する販売チャネルは？**
    - 量販店（ロフト・ハンズ等）
    - 専門店
    - 書店
    - 百貨店
    - オンライン（自社EC・Amazon・楽天）
    - SNS経由

## E. 提案構造（必須）

14. **何案提案するか？**
    - 2案（A方向 / B方向）
    - 3案（A/B/C）← 標準推奨
    - 4-5案（A〜E）

15. **各案の方向性をどう散らすか?**
    - 機能寄り / コンセプチュアル / 融合 の3分散
    - 既存路線の延長 / 飛び道具 / 第三の道 の3分散
    - 別の軸での分散

16. **二項対立の核となる軸は何か?**
    - 機能性 × デザイン性（プロダクト定番）
    - 動 × 静（ホテル・空間定番）
    - 集客 × 滞在（ホスピタリティ）
    - その他案件特有の軸

## F. 出力形式

17. **最終出力ファイル形式は？**
    - .pptx（編集可能、プレゼン向け）← 標準推奨
    - .pdf（配布用、レイアウト固定）
    - .md（ドラフトのみ）

18. **ボリュームの目安は？**
    - ミニマム版（10-15ページ）: 初回顔合わせ・コンセプト共有用
    - 標準版（20-30ページ）: クライアント社内検討用
    - フル版（40-50ページ）: 大規模案件・複数案詳細展開

## G. 補助情報（任意）

19. **過去の類似案件（社内の参照可能なもの）はあるか?**
    - PLUS系（プロダクト・ステーショナリー）
    - ホテル・施設系（Roppongi, Gora）
    - ※`references/07_examples.md` を確認

20. **クライアントの社内ヒエラルキー・意思決定者は?**
    - 主担当者
    - 決裁者
    - 社内で反対されやすいポイント

## H. 仮置きルール

ユーザーが「任せる」と言った場合、以下のデフォルトで仮置きする:

- 案数: **3案**
- 二項対立軸: **機能性 × デザイン性**（プロダクト）/ **動 × 静**（ホテル・空間）
- 章数: **標準版（20-30ページ）**
- 出力形式: **.pptx**
- バージョン: **1.0**

仮置きで進める場合は、必ず冒頭で「以下は仮置きの前提です。修正してください」と明示する。
